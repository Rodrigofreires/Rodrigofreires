### 🚀 Projetos em destaque

#### 🤖 Motor de Conteúdo com IA
Aplicação de geração de conteúdo em escala com **lauda mestra, diretrizes editoriais, camada de recompensa, aprendizado e revisores automatizados**. Integração via API para criar e atualizar conteúdo em massa direto no e-commerce.
`Python` `LLMs` `Prompt Engineering` `APIs` `VTEX`

#### 📊 Dashboard de Analytics Integrado
Visão única de performance cruzando **tráfego, URLs estratégicas, escala de mídia e ruptura de catálogo**. Junta dados de mídia paga, orgânico, feed de produtos e plataforma de e-commerce em um só lugar.
`Python` `SQL` `GA4` `Google Ads` `Search Console` `Merchant Center` `Looker Studio`

#### 📱 Publicador Integrado para Instagram
Aplicação para **planejar, agendar e publicar** conteúdos no Instagram de forma integrada ao fluxo de social media, reduzindo trabalho manual na operação de redes.
`Python` `Meta Graph API` `Automação`

#### 🎲 Rotina de Mestre — [rotinademestre.com.br](https://rotinademestre.com.br)
Portal de conteúdo sobre RPG de mesa **idealizado, desenvolvido e gerido por mim**: tema WordPress próprio, área de membros, newsletter e **criador de fichas de personagem para 11 sistemas**. Arquitetura de SEO do zero (silos, taxonomia, canonical, sitemap) e mensuração via GTM. Distribuição em YouTube, Instagram, TikTok e Discord.
